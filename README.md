# backend-Opdracht-MyFirstClass

de backend opdracht Opdracht MyFirstClass

hier onder komt hoe je het runt en de opdracht

hoe run je het(er zijn 2 manieren om dit te runnen):

manier 1 (als website openen):
1. download de code en zet hem ergens in je folders.
2. ga na waar je code staat
3. klik op de balk waar de locatie van je code staat.
4. verander wat er staat ma "cmd" (dit opent je comands)
5. run de code "php -S localhost:8000 (naam code bv. index.php)"
6. je ziet nu een link na een pagina
7. copy de link en paste hem in welke search engine je gebruikt
8. nu is je website zichtwaar

manier 2 (in de terminal):
1. download de code en zet hem ergens in je folders.
2. ga na waar je code staat
3. open deze code met visual studio code
4. klik op run "terminal" links bovenin je scherm
5. klik op "new terminal"
6. type het volgende in de terminal: "php {jouw file naam}"
7. klik op enter en het runt je code

de opdracht:
Maak een gekleurde stoel die in de hoogte verstelbaar is. Deze opdracht mag in C#, PHP of andere programmeertaal worden gemaakt, zolang een OOP-structuur te vinden is.

Zie voorbeeldcode + verwachte output. Zie index.php als het ‘programma’ (mens die op stoel wil zitten). Je gaat nu dus een stoel maken met bepaalde eigenschappen en de mogelijkheid om de hoogte in te stellen.
